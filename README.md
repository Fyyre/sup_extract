# Extract Forsaken World (Shenmo) .SUP update packages, with ease
## Fyyre - https://github.com/Fyyre

## Usage: python3 sup_extract.py
```
usage: sup_extract.py [-h] [-l] sup_file [output_dir]

Forsaken World .SUP Extractor - Fyyre https://github.com/Fyyre

positional arguments:
  sup_file    path to the .sup package
  output_dir  directory to write files into (default: ./<sup name>)

options:
  -h, --help  show this help message and exit
  -l, --list  list files instead of extracting them
```
